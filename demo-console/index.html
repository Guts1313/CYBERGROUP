STEP 1   Authenticate via Keycloak (Auth Code + PKCE + MFA)

Clicking Login redirects you to Keycloak's own hosted login page. Sign in as one of the realm users — admin-test, itmgr-test, hrmgr-test, dev-test, normal-test, all with password IAMGroup123! — complete the one-time TOTP step, and Keycloak redirects back here with an authorization code. The browser then exchanges that code for a JWT.

Flow: OAuth2 Authorization Code + PKCE (S256 challenge), public client iam-frontend, no client secret in the browser. This is the real production flow — MFA is enforced because the login happens on Keycloak's page, not here.
